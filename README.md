## A note on approach

Every case study in this repository is built the same way:

1. **Grounded in real, publicly available material** — official product documentation, published regulation, or peer-reviewed research — never invented scenarios presented as fact.
2. **Clearly disclosed** — each document states plainly that it is an independent analysis, not proprietary or insider work.
3. **Connected to real operational experience** — governance controls proposed are ones I have direct experience implementing, in CI/CD, access management, and audit contexts, applied here to AI-specific risk.

This repository is a working portfolio and will grow as new pieces are completed.
